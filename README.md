# it-toolkit-public

База знаний для системного администратора широкого профиля. Агенты, чек-листы, шаблоны, скрипты-заготовки. Подключается к Claude через GitHub-коннектор и используется как knowledge базы проекта.

## Что внутри

```
agents/             # Промпт-агенты (DiagNet, RouterSetup, WinTriage, …)
checklists/         # Чек-листы по типовым задачам
templates/          # Шаблоны документов (паспорт сети, акт, отчёт)
scripts/            # Скрипты-заготовки
  ├── powershell/   # Windows-автоматизация
  ├── bash/         # Linux-автоматизация
  └── routeros/     # MikroTik / RouterOS
kb/                 # База знаний — заметки, рецепты, разбор грабель
docs/               # Документация по самому тулкиту
```

## Что НЕ хранить в этом репо
Этот репозиторий **публичный**. Сюда **никогда** не попадает:
- Имена клиентов, адреса, контакты
- Реальные IP, домены, пароли, токены, серийники
- Топологии конкретных сетей
- Снимки конфигов с боевых устройств

Всё клиентское — в приватный репо `it-toolkit-clients`.

## Как использовать с Claude
1. Создай проект в Claude.ai.
2. В Project Knowledge → Add content from GitHub → подключи этот репо.
3. В Project Instructions вставь содержимое `docs/project-instructions.md`.
4. После каждого `git push` жми **Sync now** в проекте — авто-синка по push'у пока нет.

Подробности — `docs/setup.md`.

## Как контрибьютить
См. `CONTRIBUTING.md`. Коротко: новый агент = новый файл `agents/agent-<имя>.md` + строка в `agents/README.md`.
