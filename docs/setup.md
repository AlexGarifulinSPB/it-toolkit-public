# Setup: Claude + два репо

## Идея
- **Публичный репо** (`it-toolkit-public`): агенты, шаблоны, чек-листы, скрипты. Не содержит ничего клиентского.
- **Приватный репо** (`it-toolkit-clients`): паспорта клиентов, инциденты, специфика.

Под это поднимается **один или два проекта в Claude** — выбирай по вкусу.

## Вариант A — один проект, два репо (рекомендую)

Один проект в Claude, в knowledge подключены оба репо. Удобно: когда упоминаешь клиента по имени, Claude видит и общие материалы, и его паспорт.

### Шаги

1. Создай проект в Claude.ai. Назови, например, `IT Support`.
2. **Project Instructions** → вставь содержимое `it-toolkit-public/docs/project-instructions.md`.
3. **Project Knowledge → + → Add from GitHub:**
   - Подключи `it-toolkit-public` (public). Включи папки: `agents/`, `checklists/`, `templates/`, `kb/`, `docs/`. Папку `scripts/` можно отключить, если не хочешь раздувать контекст — Claude всё равно умеет писать скрипты, файлы тут просто как примеры стиля.
   - Подключи `it-toolkit-clients` (private). Включи всё.
4. После каждого `git push` в любой из репо — открой проект и нажми **Sync now** (по push'у автоматически не подтягивается).

Минус: всё клиентское доступно во всех чатах проекта. Если работаешь параллельно над разным — нормально.

## Вариант B — два проекта

- `IT Support — Tools`: только публичный репо. Сюда лезешь, когда пилишь сами агенты/шаблоны/скрипты, без работы с клиентами.
- `IT Support — Ops`: оба репо. Сюда — когда чинишь конкретного клиента.

Минус: дублирование Project Instructions, надо синхронить две копии. Плюс: чище контекст в каждом проекте.

## Лимиты, о которых надо знать

- Содержимое подключённых репо должно влезать в контекст-окно проекта; начни с малого, добавляй по мере роста.
- Sync ручной (клик "Sync now"). Авто-синка по push'у на момент написания нет.
- Если в knowledge всплыло что-то клиентское из публичного репо — значит ты по ошибке закоммитил в public. Удаляй и переписывай историю (`git filter-repo`), потом ротируй упомянутые креды.

## Workflow на каждый день

```
Я: правлю агента в it-toolkit-public локально
Я: git commit → git push
Я: открываю проект в Claude → Sync now
Я: пишу «Запусти агента DiagNet, клиент Альфа, …»
Claude: использует свежую версию агента + паспорт Альфы
```

## Workflow при инциденте у клиента

```
1. Открыть приватный репо → клонировать локально, если ещё не
2. (Опционально) ветка: git switch -c incident/alpha-2026-04-30
3. По ходу работы — фиксировать в clients/<client>/incidents/INC-NNNN.md
4. После закрытия — push, Sync now, попросить агента PostMortem собрать отчёт
```
