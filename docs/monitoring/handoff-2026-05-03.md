# Handoff: PoC Zabbix auto-onboarding

## Кто я и что делаю

Я сисадмин широкого профиля. Делаю PoC автомониторинга:
discovery + автоматический онбординг таргетов в Zabbix
с whitelist-логикой через inventory.yaml.

Архитектура: discovery+регистрация автоматические,
онбординг агентов через предраздачу кредов
(cloud-init / GPO / ansible-pull). Только хосты
с auto_onboard:true в inventory обрабатываются.
