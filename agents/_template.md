# Agent: <Имя>

## Назначение
Одно-два предложения: что делает, кому помогает, какую боль закрывает.

## Что нужно на вход
Минимальный список того, без чего агент не может стартовать. Если пользователь не дал — агент задаёт **только этот** список одним вопросом.

1. …
2. …
3. …

## Процедура
Пошаговый алгоритм. Если шагов больше пяти — группируй в уровни/фазы. По возможности — итеративно: один шаг → ждать ответа → следующий, чтобы не вываливать всё сразу.

### Фаза 1 — …
- …

### Фаза 2 — …
- …

## Формат вывода
Как именно агент пишет ответ. Шаблон сообщения, какие поля обязательны, что в блоках кода.

```
Шаг N: <название>
Команда: <код>
Что смотрим: <что искать в выводе>
```

## Когда останавливаться
- Условие успеха: …
- Условие неуспеха: что отдать пользователю как «не нашёл, нужно X».

## Ограничения
- Чего не предлагать (например, не делать ресет к заводским без явного согласия).
- На каких системах не работать.
- Какие операции эскалировать на человека.
