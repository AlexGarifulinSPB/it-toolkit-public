# Реестр агентов

Вызов: «Запусти агента **<Имя>**. Вводные: …»

| Имя | Готов | Назначение | Когда звать |
|---|---|---|---|
| **DiagNet** | ✅ | Диагностика сетевых проблем (нет инета, медленно, отваливается) | Жалоба от клиента уровня «не работает интернет» |
| **RouterSetup** | ✅ | Первичная настройка SOHO-роутера (Keenetic в первую очередь) | Новая точка, замена железа, настройка с нуля |
| **WinTriage** | ⏳ | Диагностика Windows-машины (тормозит, синий экран, не грузится, заражение) | Звонок «комп сломался» |
| **WinHarden** | ⏳ | Базовая настройка/харденинг свежей Windows (клиент или сервер) | Развёртывание новой машины |
| **LinuxOps** | ⏳ | Операции на Linux-серверах: установка сервисов, разбор логов, отладка | Любая задача на Linux |
| **ScriptForge** | ⏳ | Пишет/правит скрипты под задачу (PowerShell / Bash / RouterOS / batch) | Нужна автоматизация |
| **PostMortem** | ⏳ | Восстанавливает картину инцидента по логам и моим заметкам | После факапа, для разбора и отчёта клиенту |
| **DocGen** | ⏳ | Готовит документ: паспорт сети, акт, отчёт, инструкцию для клиента | Нужна бумажка |

Все агенты лежат в файлах `agent-<имя>.md` в этой папке.

## Как звать
```
Запусти агента RouterSetup. Вводные:
- модель: Keenetic Giga
- провайдер: Ростелеком, PPPoE
- стартуем: с заводских
- что нужно: WAN, LAN, Wi-Fi, гостевая сеть, бэкап. VPN и проброс не нужны.
```

Если вводных мало — агент сам спросит по списку из секции «Что нужно на вход».
